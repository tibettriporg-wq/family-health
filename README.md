# 家庭健康小助手 · 使用说明

## 这是什么
一个给全家人用的健康记录小工具。每个人有自己的入口，每天记录睡觉起床时间、
血压、血糖和一日三餐，页面会自动总结出注意事项。

## 怎么打开
**重要：不要双击这个文件直接打开。**

请把 `家庭健康小助手.html` 放到一个网站上（或者用下面任一方式），
拿到一个 `https://` 开头的网址，再用**手机浏览器**打开那个网址。

> 为什么？浏览器在直接打开本地文件（file://）时，会限制网页保存数据，
> 你填的记录就存不住。有了正式网址才能真正保存。

## 三种发布方式（按省事程度排）

### 方式一：Gitee Pages（推荐，国内快）
1. 注册 https://gitee.com
2. 新建一个仓库，把 `家庭健康小助手.html` 上传进去
3. 仓库 → 服务 → Gitee Pages → 点「启动」
4. 拿到 `https://你的用户名.gitee.io/仓库名/家庭健康小助手.html`

### 方式二：Vercel / Netlify（拖拽即可）
1. 打开 https://vercel.com 或 https://netlify.com
2. 把整个文件夹拖进去
3. 几秒后得到 https 网址

### 方式三：腾讯云 COS / 阿里云 OSS
上传文件 → 开启静态网站功能 → 拿到访问网址

## 怎么用

### 首页
- 看到全家人的卡片，点谁就进谁的主页
- 卡片右下角的 **✏️** 可以直接改这个人的档案
- 顶部绿色条显示「✅ 数据已保存到这台设备」= 一切正常

### 个人主页
点「现在填一下」开始今天的记录：
- **睡眠**：睡觉时间 + 起床时间（会自动算睡了几个小时）
- **血压**：高压 / 低压
- **血糖**：数值 + 选时机（空腹 / 餐后 / 睡前）
- **一日三餐**：可点选项，也可以自己写

填完点「保存」，页面会自动给出**今天的注意事项**，包括：
- 血压分级判断
- 血糖判断（按空腹/餐后不同标准）
- 睡眠时长 + 入睡是否过晚
- 三餐问题提醒
- 最近几天的趋势告警（比如连续偏高、连续缺觉）
- 慢性病联动提醒（有高血压 / 糖尿病会说得更具体）

### 另外两个标签
- **历史**：按日期翻看每个人的记录
- **趋势**：血压、血糖、睡眠、饮食的近期走势
- 底部还有 **科普** 和 **防坑** 两个栏目

## 关于隐私
所有数据只存在你自己的手机 / 电脑浏览器里，**不会上传到任何服务器**，
也没有任何账号系统。换设备或清理浏览器数据后记录会丢失，
重要数据建议定期截图留存。

## 遇到问题

**提示「保存失败」怎么办？**
- 先看页面顶部的提示条，它会说明具体原因
- 如果显示蓝色「预览模式」→ 说明你还在预览窗口里，按上面步骤正式发布即可
- 点提示条上的「查看详细原因」，把弹出的信息发给我，我能定位问题

**数据能存多久？**
只要不清理浏览器数据、不用无痕模式，就会一直保留。
